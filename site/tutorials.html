📖 手机动态壁纸设置教程

不同品牌的手机设置动态壁纸的方式略有差异。以下是主流品牌的设置方法。

💡 通用方法：保存视频到相册后，在图库中打开 → 点击"更多" → "设置为壁纸" → 选择"动态壁纸"→ 确认。

📱 iPhone（iOS）

🍎 iOS 18+ 原生设置

  1. 在 X 上打开视频，长按 → 保存到相册
  2. 打开「设置」→「壁纸」→「添加新壁纸」
  3. 选择「动态壁纸」→ 从相册选取视频
  4. 调整位置后点击「添加」

🍎 iOS 16-17 使用快捷指令

  1. 下载「IntoLive」App（App Store 免费）
  2. 保存视频到相册 → 在 IntoLive 中打开
  3. 选择「Live Photo」转换 → 保存
  4. 主屏幕长按 → 选择壁纸 → 选择刚保存的 Live Photo

📲 IntoLive

App Store 免费下载。将视频转换为 Live Photo，支持截取片段、调整速度。

📲 Wallpaper Engine (iOS)

App Store 付费。支持视频循环播放、动态壁纸管理与定时切换。

📱 Android

🟢 通用方法（大部分 Android 13+）

  1. 保存视频到相册（X 长按视频 → 保存）
  2. 打开「图库」→ 找到视频 → 点击右上角菜单
  3. 选择「设置为壁纸」→ 「动态壁纸」（或「视频壁纸」）
  4. 裁剪调整 → 确认

📱 三星 Galaxy ｜ One UI

  1. 安装「Good Lock」→ 安装「Wonderland」插件
  2. 或直接：设置 → 壁纸和风格 → 更多壁纸 → 动态壁纸
  3. 选择「视频壁纸」→ 从相册选取视频
  4. 调整后确认
💡 三星 One UI 6+ 原生支持视频壁纸，无需第三方 App。

📱 华为 / 荣耀 ｜ HarmonyOS / EMUI

  1. 设置 → 壁纸和个性化 → 壁纸 → 动态壁纸
  2. 点击「更多」→ 从相册选取视频
  3. 调整预览 → 应用
💡 部分机型需在「主题」App 中设置：主题 → 我的 → 混搭 → 壁纸 → 动态壁纸。

📱 小米 / 红米 ｜ HyperOS / MIUI

  1. 相册中打开视频 → 点击底部「更多」→ 「设置为壁纸」
  2. 或：设置 → 壁纸 → 动态壁纸 → 从相册选择
  3. 调整后确认
💡 MIUI 14+ 原生视频壁纸支持。HyperOS 支持锁屏与主屏分别设置。

📱 OPPO / 一加 ｜ ColorOS

  1. 设置 → 壁纸和个性化 → 壁纸 → 动态壁纸
  2. 选择「视频壁纸」→ 从相册选取
  3. 调整 → 应用

📱 vivo / iQOO ｜ Funtouch OS

  1. 打开「i主题」App → 我的 → 壁纸 → 动态壁纸
  2. 选择「自定义」→ 从相册选取视频
  3. 调整 → 应用

📱 Google Pixel ｜ 原生 Android

  1. 设置 → 壁纸和样式 → 更多壁纸
  2. 选择「动态壁纸」→ 从相册选取
  3. 调整 → 设置壁纸

❓ 遇到问题？

⚠️ 视频比例不匹配：壁纸会被裁剪填充。建议选择与手机屏幕比例接近的壁纸（使用站内比例筛选功能）。
⚠️ 视频自动播放无声音：动态壁纸默认静音，这是正常设计。
🔄 建议选择 6-10 秒的短循环视频，观看体验最佳。
